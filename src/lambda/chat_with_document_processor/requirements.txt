# Pin a newer boto3 than the Lambda runtime default (currently ~1.35) so that
# the ``serviceTier`` parameter is supported by ``bedrock-runtime.converse_stream``.
# Service-tier support (``priority`` / ``flex``) was added to the Converse *non*-stream

# Bedrock rejects ``serviceTier`` client-side with a boto3 ParamValidationError before
# the request is ever sent:

#   system, inferenceConfig, toolConfig, guardrailConfig, additionalModelRequestFields,
#   promptVariables, additionalModelResponseFieldPaths, requestMetadata, performanceConfig
# Lambda will use the version pinned here over the runtime default when it's newer.
